Privacy Policy

Last updated: November 25, 2026

This policy covers the website realityhasplot.github.io and the "Reality Has Plot Studio" application, an internal tool used only by the owner of the YouTube channel Too Strange to Script (formerly Reality Has Plot) to upload and schedule the channel's own videos.

Website

This website does not use cookies, analytics, ads or forms, and does not collect personal information. It only contains links to the channel and contact information.

Reality Has Plot Studio (Google / YouTube API)

  • The application is used exclusively by the channel owner, with the owner's own Google account.
  • It uses the YouTube Data API to upload videos, upload captions and read basic information about the owner's own channel (scopes: youtube.upload, youtube.readonly, youtube.force-ssl).
  • The access token is stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising.
  • The application does not access data from any other YouTube user.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
  • Access can be revoked at any time at myaccount.google.com/permissions.
